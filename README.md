# Orca CRM

Orca CRM is a full-stack customer relationship management application built using the MERN stack.  
The project focuses on managing customer data, follow-ups, notes, team assignments, and workflow tracking through a modern dashboard interface.

This project was built as a practical attempt to understand how real-world SaaS applications are structured and developed.

---

# Features

## Authentication
- User signup and login
- JWT based authentication
- Protected frontend routes
- Secure backend middleware validation

## Customer Management
- Add new customers
- Edit customer details
- Delete customers
- Assign customers to team members
- Store customer company information
- Track customer status and priority

## Notes System
- Add notes for each customer
- Edit notes
- Delete notes
- Timeline style interaction tracking

## Dashboard Layout
- Responsive sidebar navigation
- Collapsible sidebar
- Sticky navigation bar
- Dynamic page routing using React Router

## UI/UX
- Modern SaaS inspired interface
- Lottie animations
- Sticky table headers
- Scrollable customer table
- Reusable modal components
- Icon based action buttons
